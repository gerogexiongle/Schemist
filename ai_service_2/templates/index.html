FAQ
如何提高SQL生成质量?
提供清晰、具体的业务需求描述（目标、时间范围、筛选条件等），并结合已索引的库表与分区习惯进行问询。
为什么有时生成的SQL不准确?
SQL 生成依赖本地载入的 JSON Schema（如 hivebrain）；元数据不完整或需求模糊时可能影响准确性。
如何查看数据可视化效果?
执行SQL查询后，点击"可视化数据"按钮，选择适合的图表类型和数据列，即可生成数据可视化图表。
如何获取帮助?
开源版本请参阅仓库 README / Issue；企业内部部署请咨询平台管理员。
